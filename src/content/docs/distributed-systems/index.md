# Distributed systems

This category owns concepts that arise when independent nodes communicate over a network and no single process can observe or control the full system state.

Concurrency entries own shared-state and synchronization mechanisms inside or across workers. Database entries own storage-specific transaction and isolation behavior. Reliability entries own failure-handling mechanisms such as timeouts, retries, circuit breakers, and load shedding.

Distributed-systems entries focus on partial failure, replication, consistency, ordering, consensus, and coordination across network boundaries.
