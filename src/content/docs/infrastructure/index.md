# Infrastructure

This category owns provider-neutral infrastructure concepts that shape where software runs and how runtime capacity is created, configured, replaced, and scaled.

Delivery entries own promotion and release flow. Security entries own trust and secret-handling principles. Reliability and observability entries own failure handling and evidence.

Infrastructure entries explain the runtime substrate and its reproducibility boundaries.
