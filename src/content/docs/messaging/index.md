# Messaging and event streaming

This category owns asynchronous communication through queues, publish-subscribe channels, durable event streams, and consumer coordination.

Architecture entries own event-driven system structure. Reliability entries own generic retries, idempotency, and backpressure. Database entries own transaction boundaries.

Messaging entries explain how those concepts combine at message-delivery boundaries.
