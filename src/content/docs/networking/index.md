# Networking

This category owns product-neutral networking concepts that application engineers need to reason about request paths, latency, failure, caching, and transport security.

API design entries own application contracts. Reliability entries own failure-handling policies such as timeouts and retries. Security entries own broader trust and authorization controls.

Networking entries explain the mechanisms below those boundaries: DNS, transport protocols, TLS, HTTP, intermediaries, caching, and connection reuse.
