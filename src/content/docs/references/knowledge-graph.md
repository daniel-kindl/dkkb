# Knowledge graph

The DKKB knowledge graph derives connections from canonical Markdown links and `related` metadata.

Use the controls below to focus one entry at a time. The visual view shows a bounded neighborhood instead of rendering the whole repository as one dense graph.

Markdown-link and `related` relationships keep their direction. Every focused relationship is also available as a normal text link for keyboard and non-visual navigation.

The graph is an optional discovery tool. Canonical Markdown pages and Starlight navigation remain the primary knowledge interface.
