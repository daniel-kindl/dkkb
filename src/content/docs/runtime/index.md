# Operating systems and runtime

This category owns product-neutral operating-system and runtime abstractions that affect application concurrency, memory, I/O, and performance.

Concurrency entries own synchronization and ordering rules. Performance entries own measurement and profiling. Networking entries can build on the I/O concepts here without making one operating system authoritative.

Runtime entries explain the resource and execution mechanisms below application code.
