# Visual hierarchy, typography, and density

Visual hierarchy communicates which information is primary, which items belong together, and where attention should move next.

Typography is one of the main hierarchy systems. Size, weight, spacing, line length, alignment, and position can establish relationships before color or decoration is added.

## Build hierarchy from meaning

Use a small number of repeatable text and emphasis roles. A heading level should represent document structure, not only a preferred visual size.

Make primary actions and critical state easier to find without making every important item visually loud. When many elements compete for attention, none has clear priority.

## Design type for reading

Choose type sizes, line spacing, line length, contrast, and font characteristics that remain readable across supported viewport sizes and zoom levels.

Avoid using very small text to increase information density. Dense expert interfaces can still use clear grouping and legible type.

## Treat density as a task decision

High density can help comparison and monitoring tasks because more relevant information stays visible. Low density can help focused, infrequent tasks by reducing competing information.

Do not equate whitespace with usability. Excessive spacing can force scrolling and break comparison just as insufficient spacing can make structure unclear.

## Limits

Visual hierarchy cannot replace semantic structure. Screen readers, keyboard navigation, zoom, and alternate presentation modes need structure that survives beyond the default visual layout.
