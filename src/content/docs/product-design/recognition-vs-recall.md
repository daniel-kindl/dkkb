# Prefer recognition over recall

Recognition is usually easier and more reliable than recalling information from memory without a visible cue.

Interfaces can reduce unnecessary memory work by keeping relevant actions, choices, instructions, and previously entered context available when users need them.

## Examples

Recognition-oriented design can include:

- visible menu choices instead of requiring command recall;
- recent or suggested values where they are safe and relevant;
- labels paired with icons rather than unexplained icons alone;
- showing current filters and selections;
- preserving context across multi-step workflows.

## Trade-offs

Making everything visible can create clutter and increase scanning cost. Recognition should not become an excuse to expose every possible action simultaneously.

The useful balance depends on task frequency, user expertise, available space, and the cost of choosing the wrong action.

Expert interfaces can also support recall-based shortcuts, such as keyboard commands, while keeping discoverable recognition-based paths available.
