# Affordances and signifiers

An affordance is a possible interaction between a person and an object or interface. A signifier is a perceivable cue that communicates where or how an action can occur.

In digital interfaces, the distinction matters because an action can technically exist without being discoverable. A clickable region with no visual, textual, or structural cue may afford activation while failing to signify it.

## Practical implications

Useful signifiers can include:

- familiar control shapes and labels;
- visible boundaries for interactive regions;
- cursor, focus, hover, or pressed states where appropriate;
- conventional placement and terminology;
- feedback after an action begins or completes.

## Avoid false signifiers

Visual treatment should not imply an interaction that does not exist. Text that looks like a link but is not clickable, decorative controls that resemble buttons, or inconsistent states create misleading expectations.

## Limits

No single visual style guarantees discoverability. Familiarity varies across platforms, cultures, and user experience.

When an action is important or irreversible, explicit labeling is often more reliable than relying only on visual resemblance or convention.
