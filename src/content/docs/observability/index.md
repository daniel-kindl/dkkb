# Observability

Make system behavior visible enough to diagnose failures, understand performance, and validate production behavior.

Observability covers the signals and practices used to infer internal behavior from external outputs. It owns signal design, context, interpretation, and operational feedback.

- [Reliability](/dkkb/reliability/) explains behavior under faults, partial failure, and recovery.
- [Performance](/dkkb/performance/) explains resource use, latency, throughput, and optimization.
- [Testing](/dkkb/testing/) explains verification before deployment.
- Observability explains how production evidence supports those activities.
