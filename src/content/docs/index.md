# Daniel Kindl Knowledge Base

DKKB records software engineering knowledge from literature, primary sources, practical experience, experiments, and derived guidance.

The repository is the source of truth. Each entry should help the reader understand a concept, solve a problem, or make an engineering decision.

## How to use DKKB

Use the topic areas in the sidebar or search for a concept directly.

When an entry gives guidance, read its context and trade-offs before you apply it. A pattern that is useful in one system can add unnecessary complexity in another.

## Knowledge model

DKKB distinguishes general engineering knowledge from personal playbook guidance.

General entries describe concepts, evidence, and trade-offs. Playbook entries state preferred engineering defaults and must make their scope clear.
