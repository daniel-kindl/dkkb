# Data structures

This category owns language-neutral data-structure concepts used to reason about lookup, insertion, ordering, traversal, memory, and bounded work.

Database entries own storage-engine and query-planning behavior. Performance entries own measurement and system-level optimization.

Data-structure entries explain the shape and operation trade-offs that support those higher-level decisions.
