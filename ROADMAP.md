# DKKB roadmap

## Phase 1: Foundation

- establish the Markdown content model
- publish the Astro and Starlight site
- configure GitHub Pages deployment
- establish writing, source, and governance policies
- establish deterministic quality checks
- define the initial taxonomy

## Phase 2: Core engineering knowledge

- add foundational software engineering principles
- add common architecture concepts
- add design patterns and anti-patterns
- add recurring engineering problems and failure modes
- add testing, reliability, performance, and security foundations

## Phase 3: AI and LLM engineering

- add AI-assisted development guidance
- add LLM application architecture concepts
- add evaluation, retrieval, tool use, and context engineering topics
- record practical observations separately from general claims

## Phase 4: Knowledge quality

- improve cross-linking and taxonomy consistency
- review source quality and stale references
- add lightweight checks only when repeated errors justify them
- improve retrieval for people and AI agents without changing the canonical Markdown model
